Welcome to the CS-300 Analysis and Design Assignments Repository! 
This repository contains a collection of assignments aimed at enhancing your understanding and application of various concepts in analysis and design in computer science.


Project One: The problem I tackled in Project One was analyzing the runtime and memory usage of various data structures under different scenarios. I aimed to understand how different data structures perform in terms of time complexity and memory consumption, which is crucial for making informed decisions in software development. 

Approaching this problem involved first selecting a set of common data structures such as arrays, linked lists, stacks, queues, trees, and hash tables. Then, I designed experiments to measure the time taken and memory consumed by each data structure for different operations like insertion, deletion, and search. By running these experiments and analyzing the results, I gained insights into the strengths and weaknesses of each data structure. 

Understanding data structures is fundamental in software development because they serve as the building blocks for solving various computational problems efficiently. Different data structures are optimized for different operations, and having a deep understanding of them allows developers to choose the most appropriate one for a given problem, leading to better performance and scalability of software systems. 

Overcoming roadblocks during this project involved thorough research and experimentation. I encountered challenges in accurately measuring runtime and memory usage, especially for smaller operations where the overhead of measurement could significantly affect the results. To overcome this, I fine-tuned my experimental setup and used appropriate tools and techniques to minimize measurement errors. 

Project Two: In Project Two, the problem involved sorting and printing a list of courses in the Computer Science program in alphanumeric order. While seemingly straightforward, this required applying sorting algorithms to arrange the courses alphabetically. 

My approach to solving this problem was to implement a sorting algorithm, such as merge sort or quicksort, to sort the list of courses alphabetically. I then wrote code to print the sorted list to the console in the desired format. 

This project expanded my approach to designing software by reinforcing the importance of algorithmic thinking. It highlighted the significance of choosing the right algorithm for the task at hand, considering factors such as time complexity, space complexity, and the size of the input data. 

Furthermore, working on this project reinforced the importance of writing clean, maintainable, and readable code. By adhering to coding best practices such as using meaningful variable names, writing modular code, and providing comments/documentation, I ensured that my code was easy to understand and maintain. 

In summary, these projects have deepened my understanding of data structures and algorithms, enhanced my problem-solving skills, and reinforced the importance of writing high-quality code. They have equipped me with valuable skills and insights that I can apply in future software development endeavors.
